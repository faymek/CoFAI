# Plain-DETR components

These internal modules implement the ViT-L/16 Plain-DETR head used by the COCO test plan. CoFAI supplies four intermediate feature maps; the head constructs the encoder, relative-position decoder and prediction layers directly.

The components are adapted from the DINOv3 Plain-DETR detection implementation. Upstream copyright notices are retained in the source files; see [LICENSE.md](LICENSE.md).
