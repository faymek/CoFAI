# PQFCv2 K2048e8 最佳模型与复现

保留的最佳模型：`/data4/workspace/zlt/featcodec/CoFAI/weights/pqfcv2/dinov3/k2048_8h_candidates/rate125_epoch01_assign10000_stage2.npz`。SHA-256：`eafbe004c1fff7eed14899a4295b825e554a6c0d04a91fbfb3bc48dd7a47e1bd`。

该文件包含 `R`、`codebooks`、`pmf`、`prefix_position_channel_rms`、`patch_channel_rms` 和推理赋值 `lmbda=10000`。其中 R、码本、PMF 与原实测模型一致；RMS 与原始 RMS 一致。Stage 1 实测：ADE 5.48602965 bpp / 0.48517496 mIoU；NYU 5.08114934 bpp / 0.39797856 RMSE / 0.88435468 a1。Stage 1 测试数据包括 ADE 2000 张、NYU 654 张；bpp 统计 rANS 实际 payload，不含共享模型和单独形状状态。

最佳模型训练参数见 `examples/pqfcv2/configs/stage1_k2048e8_8h_rate125.yaml`；原 OPQ、原 RMS、原分割及 grids 索引需保留。训练时赋值 λ 为 100，最终导出时设置为 10000。现有 Stage 2 使用最近邻量化并忽略该 λ；其 token adapter 是块内跨 token 变换。旧 Stage 2 adapter checkpoint 与新 NPZ 的 SHA-256 绑定不一致，需使用新 NPZ 重新训练 Stage 2。

下面的操作在 `CoFAI-dev` 仓库根目录执行。清理后，若要重新训练 Stage 1 或 Stage 2，先从原始图像重提取两万份特征。以下示例使用一张可用 GPU，不修改保留的 split、grids 或 RMS：

```bash
export PROJECT_ROOT=/data4/workspace/zlt/featcodec/CoFAI
export PYTHONPATH=/data4/workspace/zlt/featcodec/CoFAI-dev
export CUDA_VISIBLE_DEVICES=0
/data4/workspace/zlt/featcodec/CoFAI/.venv/bin/python examples/pqfcv2/extract_features.py \
  --project-root "$PROJECT_ROOT" \
  --ade-list "$PYTHONPATH/examples/vq_ufc/dinov3/data_lists/ade_1w.txt" \
  --nyu-list "$PYTHONPATH/examples/vq_ufc/dinov3/data_lists/nyu_train_1w.txt" \
  --ade-root "$PROJECT_ROOT/data/ADEChallengeData2016/images/training" \
  --nyu-root "$PROJECT_ROOT/data/NYU" \
  --ade-out "$PROJECT_ROOT/features/pqfcv2/dinov3/ade" \
  --nyu-out "$PROJECT_ROOT/features/pqfcv2/dinov3/nyu" --device cuda:0
```

然后重训并从第一轮快照导出新文件（输出路径必须不存在，避免覆盖保留的最佳文件）：

```bash
/data4/workspace/zlt/featcodec/CoFAI/.venv/bin/python -u examples/pqfcv2/train_stage1.py \
  --config examples/pqfcv2/configs/stage1_k2048e8_8h_rate125.yaml --gpu 0
/data4/workspace/zlt/featcodec/CoFAI/.venv/bin/python examples/pqfcv2/scripts/export_stage2_compatible.py \
  --source "$PROJECT_ROOT/weights/pqfcv2/dinov3/stage1_K2048_e8_8h_rate125/epoch_01.npz" \
  --rms "$PROJECT_ROOT/weights/pqfcv2/dinov3/prefix_position_patch_rms_s42.npz" \
  --output /path/to/a/new/best_stage2_compatible.npz --assignment-lambda 10000
```

固定 seed 和配置用于重现流程；GPU、库版本及非确定性计算可能使重训结果和文件哈希不同。`export_stage2_compatible.py` 仅做格式打包并保留来源哈希；模型内容以保留的最佳 NPZ 为准。

Stage 2 训练/评测入口及参数见 `examples/pqfcv2/README-stage2.md`，通过 `STAGE1` 指定上述兼容 NPZ；Stage 2 训练前仍需先重提取特征。Stage 1 全量实际码流评测入口为 `examples/pqfcv2/scripts/eval_k2048.sh`。
